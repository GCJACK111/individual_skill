# 文献逻辑梳理与简化总结

面向初学者梳理学术论文：背景与问题 → 方法与数据 → 实验与结果 → 结论与研究启发。

## 使用

向助手提供论文，调用 `paper-logic-simplifier`，或在对话中提供 `SKILL.md` 的内容。

> 请按这个 skill 完整解读论文，并在当前对话中生成完整总结的 PDF 文件供我下载。

助手在完成总结后，直接使用当前会话可用的文件生成工具创建 PDF，并在对话中提供真实文件附件或下载链接。PDF 应包含全部总结章节，并检查中文与分页；具体要求见原版 `SKILL.md`。

## 文件

- `SKILL.md`：完整的文献解读流程与 PDF 交付要求。
- `agents/openai.yaml`：技能显示信息和默认调用提示。
- `LICENSE`：MIT 开源许可证。
