# 从论文原 PDF 提取路线、模型与性能图表

## 阅读与定位

1. `inspect_paper.py inspect` 提取带实际页码的全文；用 `rg` 搜索 `Fig`、`Figure`、`Table`、`architecture`、`framework`、`ablation`、`performance`、`validation`、`runtime` 等定位候选页。
2. 打开完整候选页，连同前后正文、图注、表下注释阅读。不要只靠提取的文字猜图表区域；多栏 PDF 的阅读顺序可能错乱。
3. 选总流程图为第一张，模型/机制图为第二张。若同一张图已完整承担两者，可只放一次。原文只有机制示意就如实称机制图，不把自绘图标成原文图。
4. 性能证据按主结果 → 消融 → 效率/迁移/案例排序。每篇可能一个，也可能多个。保留所有支撑解读结论的表图；前版已有的审校条目，除非用户要求删减或确实重复，不随意删除。

## 工具命令

```bash
python "$SKILL_DIR/scripts/inspect_paper.py" inspect --pdf "$SOURCE_PDF" --out "$WORK/source"
python "$SKILL_DIR/scripts/inspect_paper.py" preview --pdf "$SOURCE_PDF" --pages 4 8 13 --out "$WORK/pages" --grid
python "$SKILL_DIR/scripts/inspect_paper.py" crop --pdf "$SOURCE_PDF" --page 13 --box 0.05556 0.20139 0.94444 0.36574 --out "$WORK/crop.png"
```

示例坐标只对应示例原 PDF，不能套到新论文。`--grid` 的 0.1 网格用于定位，不会进入最终图。实际看过页面后填写每一个裁切框，再打开单独裁图确认。

## 坐标约定（固定）

- `page`：PDF 实际第几页，从 1 开始，不是印刷页码、期刊页码或 0 起始的库索引。
- `number`：原文标识，如 `图 6`、`表 4`、`表 A1（续）`、`扩展数据图 3`。
- `box`：`[left, top, right, bottom]`，以**显示页左上角为原点**、相对页宽/高归一化到 0–1。
- 图像坐标 `(x1,y1,x2,y2)` 在宽 W、高 H 的预览上，对应 `[x1/W,y1/H,x2/W,y2/H]`。必须使用整页预览尺寸，不能使用屏幕截图尺寸。
- pypdfium2 裁边参数为 `(left*W, (1-bottom)*H, (1-right)*W, top*H)`，脚本已经实现；不要把 top/bottom 直接作为 PDF 底部坐标。
- PDF 带特殊页面旋转/裁切框时先看预览，确认裁出的结果与显示页一致；不要未经查看沿用另一版本坐标。

## 完整性检查

**路线/模型图**：箭头方向、输入输出、全部子图和缩写必须可见。解释读图顺序，不猜未画出的结构。

**性能表**：保留全部模型行、任务列、指标名、单位、加粗/下划线、脚注、置信区间与续表。表太宽时保持完整高分辨率原图，供放大阅读；不能裁掉右侧列或只摘作者一行。可以另加局部放大，但全表仍需保留。

**性能图**：保留坐标轴、刻度、图例、误差条、颜色含义及全部子图。不可只裁最佳柱子，不可重画并改变数值。实测对照、物理模拟、消融和资源分布图要按证据类型说明。

**续表**：跨页表分别建条目，第二页在 `number` 标注“续”，解释两页是同一张表。不能把第一部分当全表。

原 PDF 中的矢量图、文字和表格不一定是嵌入图片，不能只用 extract-images。对页区域渲染能保留完整布局。默认裁图倍率 3.7（约 266 dpi），最终全栏宽 428 pt。尊重原图纵横比，不使用 AI 图片工具生成、补齐或改写论文证据。

## 版本和来源

记录原 PDF SHA-256。更换出版版/预印本/补充材料后页码和图号可能改变，应重新核对。图下注明原图号和 PDF 实际页码，正文保留 DOI/题名。技能仓库只保存自写解读、坐标和来源指纹，不捆绑出版商全文或原图；用户在自己的授权环境中提供原 PDF 后提取。
