# 公众号写法与详细 AI 研读结论

## 短正文：像文章，不像字段清单

写作主线为：**应用为什么重要 → 现有方法具体卡在哪里 → 本文采用什么设计 → 各环节怎样传递信息 → 证据支持到哪里**。不要逐段翻译摘要，不把文章主体写成「输入/输出/创新点」的干燥清单。保留模型名，用动词说明它处理什么，再解释术语。

默认 `problem` 约 100–180 中文字，`method` 约 130–220 字，`result` 约 100–180 字；根据论文难度调整，不为凑字数重复。中文标题可用场景或问题引入，例如「同一排楼，哪一面墙此刻晒得到太阳？」。不沿用参考文章的学科、作者、会议或性能数值。

写法示例（只展示表达方式，不能替代原文核验）：

> 同一片街区，上午和下午的立面阴影可能完全不同。逐点物理模拟能够刻画这种变化，但大量位置和时刻上的重复计算较慢。本文将建筑形态与太阳条件一起输入网络，预测当前条件下的立面辐照度。
>
> 模型先提取楼高、边缘与邻近建筑信息，再根据太阳条件调整空间信息之间的联系，最后还原为辐照度图。这样，太阳方向变化时，同一张建筑地图可以得到不同的受光结果。

这个顺序来自用户提供的公众号范例：先解释全局理解为何漏掉局部证据，再解释模型如何缩小关注范围。学习其「问题—机制—作用」叙事，不照搬例文内容或虚构同样的模块。

## 新读者能理解，但不改动技术含义

- 用「给相关邻楼分配不同参考权重」解释注意力，不说「模型知道谁挡了太阳」，除非真有来源验证。
- 用「阴影预测区和参考区的重合程度」解释 IoU；区分平均 mIoU 与阴影类别 IoU。
- R²、相关系数不是准确率。MAE/RMSE 说明单位；百分比误差说明分母、是否排除零值及聚合范围。
- 区分单位面积与总量、瞬时强度与累计能量、模拟参照与实测、区内验证与跨城市迁移。
- 「加入太阳角度」不自动等于学习连续时间关系；注意力权重不是物理因果证据；生成分布相似不等于逐时配对预测准确。
- 图后用 1–3 句说明先看哪里、比较什么、能得出什么。不能只把原图标题翻译一遍。

## 模型说明需要保留的信息

读者应能复述：输入资料 → 预处理/表示 → 关键模块及顺序 → 训练目标 → 直接输出 → 下游换算。只解释理解机制所需的数学；用户不要求时，不堆叠公式或完整推导。参数、消融或数值如果影响结论，应保留在证据与结论中。

方法描述必须对应原文：树模型、神经网络、几何算法、物理仿真、综述分类各用实际名称。不要给综述杜撰一个统一模型，也不把生成效果图的模块说成物理性能预测模块。

## 详细结论：每篇单独思考的五段

默认每段约 80–150 中文字，五段合计约 450–700 字，独立末页。标题可以适配论文，不能每篇复制相同空话。

1. **方法的实质贡献**：指出真正改变了哪种输入表达、信息关系、计算方式或输出尺度；解释它为何有用。不是简单复述架构名，也不是不加条件地称「先进」。
2. **实验结果支持什么**：挑关键对照与数字，说明它证明了哪一项能力；检查负面结果、类别差异、样本划分与统计口径。没报告置信区间或显著性时不要补推。
3. **使用时的边界**：具体指出分辨率、邻域范围、数据完整度、时段、域迁移或几何假设可能限制什么。作者明说的局限与 AI 推断应有清楚措辞；不把可能问题指控为论文已存在的错误。
4. **可借鉴的方法与应用场景**：默认面向这篇论文的潜在读者，说明什么任务适合借鉴、能复用哪项设计、迁移需要哪些资料或改动，以及哪些指标可以在同条件下比较。只有用户主动提供自己的研究目标，才增加针对性建议；没有目标也直接完成这一段，不追问、不虚构「我们的模型」。
5. **阅读结论与下一步**：给出可行动判断：优先复现、作为几何参照、作为下游应用证据，还是仅用于综述背景；提出一两个能区分机制的具体检验，而不是泛泛说「提高泛化、增加数据」。

开头明确：这些是结合原文的分析；新增对比与适配属于建议，尚未验证。不要把建议实验加入任务执行清单，除非用户另有授权。

## 结论中常见的不成立推断

- 总量误差近零 → 每个位置都准确：可能存在正负误差抵消。
- 年发电量算准 → 逐时阴影边界准确：时空累加可能掩盖局部偏差。
- 需求预测得分 → 遮挡预测得分：输出任务不同。
- 一个数据集的单图结果好于另一个数据集的多图结果 → 单图优于多图：样本不同。
- 使用 Transformer/神经场/注意力 → 技术必然更先进：需要同条件证据。
- 图表里有高分 → 在用户数据上已复现：原文数字与新实验结果必须分开。

## 项目语境会变化

只有用户要求与个人项目比较时，才读取当前项目说明，确认研究任务、数据、输入输出和评估条件。沿用用户当前确认的命名，不将历史例文的架构或实验安排套入新项目。引用论文的原生机制，与建议如何适配用户方法，是两件事。

本包没有固定论文库。每次根据调用者提供的论文重新写作、选图、记录原文坐标；不能复用其他论文的实验数据或结论。用户无需提供自己的研究项目，单篇论文就足以完成标准版本。不要为解释通用流程而公开任何用户未发布的研究设计。

## 综述与缺失信息

综述五段相应写：分类框架的帮助、证据范围、异质性限制、如何组织研究、哪些原始论文还需核验。保留综述实际提供的流程表或元分析表，注明不是自有模型性能。

缺字段写「原文未报告」或说明可用材料边界；不要填看起来合理的模型参数、发表年份或结果。若原文没有性能表，放真实结果图；也没有定量证据就明确说明。
