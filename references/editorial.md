# 纵向图文组织与结语

## 默认顺序

基本信息后按 **Abstract第一句 → Introduction第一自然段最后一句 → Contribution原文与解释 → 论文原图及解读 → 结语** 展开。两句原文是研究定位；方法、数据与结果沿作者贡献和图片解释。

## 两句原文与贡献

Abstract取摘要正文第一个完整句子，保留原语言，并给中文释义和一句简明解释。第一句属于背景时，照原文保留；本文具体任务可在解释中依据方法补充。Introduction取第一自然段真正的末句，跨栏、跨页时继续读取，保留引用标记。

贡献优先取作者明确列出的Contributions段落或条目。逐条按原顺序保留原文、中文释义、对应解释及图表出处。原文没有独立清单时，引用作者在摘要、引言或结论中的明确陈述并注明位置。

对应解释讲清作者具体做了什么、解决哪个问题、方法如何发挥作用及实验支持到什么范围。作者报告的能力、计划及解读者归纳分别有明确来源。

## 图片组织

贡献之后按主文Figure编号组织原图，涵盖方法流程、模型、数据与结果；用户指定范围时沿用。每图说明它回答的问题、读图顺序、模块或坐标含义、数据与结果，以及它如何支持某项贡献。相关原表紧邻对应结果解释，保留完整模型行、指标列、图例、脚注和续表。

方法、数据及结果图均可写入article.figures，由narrative.sections按顺序调用。其余性能表图放technical.performance，随相应结果说明呈现。同一张图表只出现一次。

标题应说明图的实质内容，如“合并投影区域，再计算受光面积”，而不是通用的“方法介绍”。读图说明解释原图中的模块、箭头、变量或比较，帮助读者理解证据。技术名称首次出现时紧接一句作用说明。

数据、划分、对照、指标和主要数值随相关图片解释，准确带上任务、单位、时段与统计范围。综述使用真实综述证据，几何算法、实验科学和学习模型依各自原文组织。

## 结语

结语默认用一个自然段概括研究方案、核心机制及证据支持的价值，篇幅随信息量安排。承接图文中的事实收束，必要的适用条件写在对应判断内；已在正文解释的数字无需重复堆放。分页服从可读性。

独立的未来方向、学术思考、先进性评级或问答由用户另行要求时扩展。

## Writing style

If a sentence serves only to preempt criticism rather than advance the argument, delete it.

## 来源与项目语境

每篇内容、原图及数值从本次论文重新取得，保留实际图号与PDF页码。引用原句与解释分开；同一区域内验证、跨区域迁移、模拟参照和实测观测按各自事实描述。

单篇论文即可启动。只有用户要求与个人项目比较时，才读取其当前研究说明；通用技能不携带个人未公开方案、固定论文库或特定模型的默认输入。
